# M2 — Auth, sessions, tenant resolver, RBAC, audit log

**Status:** Completed · **See:** [BACKEND-MIGRATION-STRATEGY.md §M2](../BACKEND-MIGRATION-STRATEGY.md)

## What shipped

| Area | File | Notes |
|------|------|-------|
| Password hashing | `server/auth/session.ts` | argon2 via `@node-rs/argon2` (memoryCost 19 MiB, timeCost 2) |
| Sessions | `server/auth/session.ts` | Opaque base64url token, 7-day TTL, stored in `Session` table; cookie is `httpOnly`, `sameSite=lax`, `secure` in prod |
| Permission catalog | `server/auth/permissions.ts` | Dotted strings; role → permission map for `admin`, `operator`, `member`, `viewer` |
| Session middleware | `server/middleware/auth.ts` | Populates `req.session`, `req.user`, `req.tenantId`, `req.permissions` |
| Auth routes | `server/routes/auth.ts` | `POST /auth/login`, `POST /auth/logout`, `GET /auth/me` (Zod-validated body) |
| RBAC guard | `server/middleware/auth.ts` | `requirePermission('system.admin')` etc. — throws `HttpError(403)` |
| Tenant isolation | session middleware → `req.tenantId` | Every repo query takes `tenantId` as the first parameter |
| Audit log | `server/audit.ts`, `AuditLog` model | Mutations call `audit(req, …)`; admin route exposes `GET /admin/audit` |
| Admin surface | `server/routes/admin.ts` | `/admin/tenants`, `/admin/users`, `/admin/audit` gated by `system.admin` |
| Frontend | `src/services/core.ts` | `apiFetch` now sends `credentials: 'include'` |
| Tests | `server/__tests__/auth.test.ts` | 8 tests: login/logout/me, validation, admin/operator role checks |

## How it fits together

```
HTTP request
  └─ cookieParser           → req.cookies
  └─ sessionMiddleware      → resolves session, sets req.session/tenantId/permissions
        if AUTH_REQUIRED=false (dev only): pins demo tenant + admin role
  └─ requirePermission(p)   → 401 if no session, 403 if permission missing
  └─ route handler          → calls repo with req.tenantId
        on mutation: audit(req, { action, resourceKind, resourceId, before, after })
```

## Known limitations

- No password reset / email verification flow yet.
- No CSRF token — `sameSite=lax` cookies + JSON-only API mitigate the common cases; revisit for prod.
- `Role` model not persisted — roles are JSON strings on `TenantMembership` with a hardcoded permission map. M3+ will move this to a `Role` table with a UI editor.
- Session revocation only via logout — no admin "force logout" yet.
