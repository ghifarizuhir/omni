# M3 — Domain coverage

**Status:** Completed (with caveats) · **See:** [BACKEND-MIGRATION-STRATEGY.md §M3](../BACKEND-MIGRATION-STRATEGY.md)

## What shipped

New Prisma models (all document-style: `id`, `publicId`, `tenantId`, indexed filter columns, `data` JSON):

| Model | Indexed columns |
|-------|-----------------|
| `Service` | tenantId |
| `Problem` | tenantId, status |
| `Change` | tenantId, status, scheduledStart |
| `Release` | tenantId, status |
| `Deployment` | tenantId, status (+ `environment`, `startedAt`) |
| `DeploymentLog` | tenantId, deploymentId |
| `ServiceRequest` | tenantId, status |
| `CatalogItem` | tenantId |
| `Integration` | tenantId, enabled |
| `KBArticle` | tenantId, status |

Repositories: `server/repositories/docs.ts` — generic `listDocs`/`getDocByPublicId` helper plus domain-specific accessors. Each accessor is a one-liner that keeps the call site typed against `src/types/*`.

Routes swapped to DB:
- `/services`, `/services/:id`
- `/problems`, `/changes`, `/releases`, `/deployments` (incl. `?active=true`), `/deployments/:id/logs`
- `/requests`, `/catalog`
- `/integrations` (incl. POST/PATCH/DELETE with audit emission)
- `/kb/articles`

Tests: `server/__tests__/m3.test.ts` — 12 tests including the audit-trail round-trip for integration updates.

## What stayed mock-backed (intentionally)

These remain in `src/mocks/*` and are served as static catalogs from `availability.ts`/`capacity.ts`/`platform.ts`/`itsm.ts`:

| Domain | Reason |
|--------|--------|
| Availability series, SLA targets/breaches, daily health | Derived/snapshot data; no UI mutation path |
| Capacity metrics, forecasts, time-series, recommendations | Time-series — needs a different storage approach (TimescaleDB hypertable or Postgres partition) — defer to a focused milestone |
| Platform: users (other than `/users/me`), teams, on-call, status page, AI sessions, RBAC catalog, measurement | Catalog data; users already in DB but team/role/on-call CRUD is admin-surface work for M5 |
| Improvements (financial calcs) | Computed totals helpers; move when admin financial editor lands |
| Environments | Tiny lookup; not worth a table |

The strategy doc's "remove `VITE_API_MODE=mock`" exit criterion is **not yet met** — kept the flag because of these residual mock-backed routes. Production deployment should still use `VITE_API_MODE=live`; mock mode is a dev fallback.
