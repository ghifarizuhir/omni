# M5 — Hardening

**Status:** ✅ Backlog closed 2026-05-14 (code-side); pentest + SLO encoding remain operational items · **See:** [BACKEND-MIGRATION-STRATEGY.md §M5](../BACKEND-MIGRATION-STRATEGY.md)

## What shipped

| Concern | Implementation |
|---------|----------------|
| Security headers | `helmet()` — HSTS, X-Content-Type-Options, X-Frame-Options, Referrer-Policy, COOP/CORP, etc. CSP is left off so the dev Vite origin works; configure at the edge in prod. |
| Rate limiting | `express-rate-limit` on `/api/v1/auth/*` — 20 req/min/IP. Test env raises the limit. |
| Structured logging | `pino` + `pino-http` — JSON output, request-id propagated via `x-request-id`, cookie/authorization headers and passwordHash redacted. |
| Liveness | `GET /live` |
| Readiness | `GET /ready` — runs `SELECT 1` against the DB; 503 if it fails |
| Health (legacy) | `GET /health` — uptime |
| Trust proxy | `app.set('trust proxy', 1)` so IPs from the edge proxy are honored |
| Request ID | UUID per request, surfaced in response header + log line |

## Backlog closeout (2026-05-14)

| Item | Outcome |
|------|---------|
| **OpenTelemetry scaffold** | `server/telemetry.ts` depends only on `@opentelemetry/api` and exposes `getTracer()` + `withSpan()`. Spans are no-ops until an SDK is registered; install `@opentelemetry/sdk-node` + an exporter and replace the body of `initTelemetry()` — one place to flip. |
| **CSP** | Env-gated via `CSP_ENABLED=true`. When on, `default-src 'self'`, `connect-src` includes `ws:`/`wss:` and any extras from `CSP_CONNECT_SRC` (CSV). Frame ancestors blocked. Off by default so dev Vite origin works. |
| **Per-tenant rate limit** | Applied to all `/api/v1/*` routes, `keyGenerator: req => req.tenantId ?? req.ip`. Default 600 req/min/tenant (override `TENANT_RATE_LIMIT`). |
| **DR runbook** | [docs/DR-RUNBOOK.md](../DR-RUNBOOK.md) — service tiers, RTO/RPO targets, failure-mode playbooks (DB primary lost, logical corruption, Redis lost, region outage, app bug), backup posture, comms, tabletop schedule. |

## How to run

```bash
# Dev — pretty logs:
LOG_PRETTY=true npm run server:watch

# Prod — JSON logs to stdout, ready endpoint feeds the load balancer:
NODE_ENV=production npm run server
```

## Smoke verification (done in-session)

```
GET /health  → 200 { status: "ok", uptime }
GET /live    → 200 { status: "ok" }
GET /ready   → 200 { status: "ok" } (DB reachable)
GET /api/v1/cis (no session) → 401
HEAD /health → helmet headers present (HSTS, X-Frame-Options, etc.) + x-request-id
```
