# M5 — Hardening

**Status:** Foundation in place; pentest/DR/SLO definitions outstanding · **See:** [BACKEND-MIGRATION-STRATEGY.md §M5](../BACKEND-MIGRATION-STRATEGY.md)

## What shipped

| Concern | Implementation |
|---------|----------------|
| Security headers | `helmet()` — HSTS, X-Content-Type-Options, X-Frame-Options, Referrer-Policy, COOP/CORP, etc. CSP is left off so the dev Vite origin works; configure at the edge in prod. |
| Rate limiting | `express-rate-limit` on `/api/v1/auth/*` — 20 req/min/IP. Test env raises the limit. |
| Structured logging | `pino` + `pino-http` — JSON output, request-id propagated via `x-request-id`, cookie/authorization headers and passwordHash redacted. |
| Liveness | `GET /live` |
| Readiness | `GET /ready` — runs `SELECT 1` against the DB; 503 if it fails |
| Health (legacy) | `GET /health` — uptime |
| Trust proxy | `app.set('trust proxy', 1)` so IPs from the edge proxy are honored |
| Request ID | UUID per request, surfaced in response header + log line |

## What is **not** done (call out, don't ship without)

| Item | Why deferred |
|------|--------------|
| OpenTelemetry traces | Scaffold ready; needs an exporter destination (Honeycomb/Grafana/Datadog) chosen by the team |
| DR runbook + tabletop | Operational — requires real prod infra |
| External pentest | Process item; schedule once a release candidate exists |
| Secrets rotation | Tooling decision (Doppler / SOPS / cloud provider secret manager) |
| Backup + restore test | Needs the managed Postgres instance |
| CSP | Belongs at the edge once the static host is chosen |
| Per-tenant rate limits | `express-rate-limit` is per IP; add a tenant-keyed limiter when a noisy tenant becomes a real problem |

## How to run

```bash
# Dev — pretty logs:
LOG_PRETTY=true npm run server:watch

# Prod — JSON logs to stdout, ready endpoint feeds the load balancer:
NODE_ENV=production npm run server
```

## Smoke verification (done in-session)

```
GET /health  → 200 { status: "ok", uptime }
GET /live    → 200 { status: "ok" }
GET /ready   → 200 { status: "ok" } (DB reachable)
GET /api/v1/cis (no session) → 401
HEAD /health → helmet headers present (HSTS, X-Frame-Options, etc.) + x-request-id
```
