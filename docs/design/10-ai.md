Tool-calling loop (future): LLM → `tool_call` → `req.scoped.*` → `tool_result` → LLM → final answer. Tools: `get_entity`, `search_entities`, `create_*`, `update_*`, `get_ci`, `search_cis` (scoped, sama seperti terra 10-ai).

## Safety

- **Scope-aware tools.** Semua tool call lewat `req.scoped` — tidak pernah direct Prisma.
- **Confirmation.** `create`/`update` tools butuh user confirm di UI sebelum execute (seperti terra `TOOL_CONFIRMATION`).
- **Untrusted context.** Entity data yang di-inject ke prompt adalah untrusted — escape `<entity_context>` block, jangan follow instruction di dalam field value.
- **No secrets in prompt.** `GEMINI_API_KEY` tidak pernah masuk prompt.
